# משקל OKOK – ללא פרסומות

אפליקציית ווב פשוטה שמתחברת למשקל OKOK/Chipsea דרך Bluetooth ומציגה את המשקל בלי פרסומות, בלי חשבון, ובלי מעקב.

## כתובת האתר

לאחר העלאה ל-GitHub Pages, הכתובת תהיה:

```
https://<שם-המשתמש-שלך>.github.io/okok-scale/
```

כדי להעלות, הרץ בטרמינל:
```bash
gh auth login        # פעם ראשונה בלבד
bash deploy.sh
```

## שימוש באייפון

### התקנת Bluefy

Safari באייפון לא תומך ב-Bluetooth מהדפדפן. צריך דפדפן אחר:

1. פתח את ה-App Store
2. חפש **Bluefy – Web BLE Browser**
3. התקן (חינם)

### פתיחת האפליקציה

1. פתח את **Bluefy**
2. הזן את כתובת האתר בשורת הכתובת
3. ברגע שהדף נטען, אפשר להמשיך

### חיבור למשקל

1. **עלה על המשקל** כדי להעיר אותו (המשקל צריך להיות דולק כדי שהטלפון ימצא אותו)
2. לחץ על **״התחבר למשקל״**
3. תיפתח רשימה של מכשירי Bluetooth — בחר את המשקל שלך (יופיע בשם כמו **ADV**, **Chipsea-BLE**, **Yoda0**, או שם דומה)
4. אם לא מוצא, לחץ על **״לא מוצא? הצג את כל המכשירים״**
5. **עלה על המשקל** — המשקל יופיע על המסך בגדול
6. כשהמשקל מתייצב, הוא יישמר אוטומטית בהיסטוריה

### הוספה למסך הבית

כדי לפתוח את האפליקציה בלחיצה אחת, בלי שורת כתובת:

1. ב-Bluefy, פתח את הדף
2. לחץ על כפתור השיתוף (ריבוע עם חץ למעלה)
3. בחר **״הוסף למסך הבית״** (Add to Home Screen)
4. לחץ **״הוסף״**

האייקון יופיע במסך הבית כמו אפליקציה רגילה.

## שימוש במחשב

1. פתח **Google Chrome**
2. גלוש לכתובת האתר (או פתח את הקובץ `index.html` ישירות)
3. לחץ על **״התחבר למשקל״**
4. בחר את המשקל מהרשימה
5. עלה על המשקל

## היסטוריה וייצוא

- כל מדידה יציבה נשמרת אוטומטית בדפדפן (localStorage)
- אפשר למחוק מדידות בלחיצה על **×** ליד כל שורה
- אפשר לייצא את כל ההיסטוריה לקובץ CSV בלחיצה על **״ייצוא CSV״**

## משקלים נתמכים

האפליקציה תומכת במשקלי OKOK/Chipsea בכל הפרוטוקולים הנפוצים:

- **V20** (מזהה יצרן 0x20CA) — משקלים חדשים יותר עם מדידת עכבה
- **V11** (מזהה יצרן 0x11CA) — פרוטוקול ישן יותר
- **VF0** (מזהה יצרן 0xF0FF) — משקל פשוט
- **C0** (בית תחתון 0xC0) — וריאנט נוסף (Yoda0 ואחרים)
- משקלים עם שירות BLE סטנדרטי (Weight Scale 0x181D)
- משקלים עם שירות Chipsea מותאם (0xFFF0)

## פתרון בעיות

- **המשקל לא מופיע ברשימה**: ודא שהמשקל דולק (עלה עליו). נסה ״הצג את כל המכשירים״.
- **הדפדפן לא תומך ב-Bluetooth**: באייפון חובה להשתמש ב-Bluefy. במחשב — Chrome.
- **המשקל מופיע אבל לא מציג ערך**: ייתכן שזה דגם שונה. נסה לעלות על המשקל שוב.
